Group management for teams, clubs and communities.

A club runs on a few people giving up their evenings. WayClub gives them one place for meetings, tasks and events, and gives everyone else one place to find what is on and say they are coming. When the committee changes, the next one inherits all of it.

Find your club

Every club has its own page, in its own colours, with what it is running next. A club shares the link; anyone can see what is on and join in a tap.

Say you're coming

One button to register, and a door code waiting when you arrive. Your plans keeps everything you said yes to in one list, so nobody scrolls a group chat for the address.

Run the committee

The workspace opens on the questions a committee actually asks: what is happening now, what is waiting on me, and what is due this week. Events move from being planned to waiting for a yes, published and done.

Meet, decide, follow up

A meeting has an agenda before it and minutes after it. Tasks come out of the minutes with a person and a date, and confirmed minutes stop changing.

Hand it over

Most clubs lose something every year: the Instagram password, the shared drive, the projector. A handover lists what the outgoing committee passes on and checks each item with the person receiving it, so next year starts where this one ended.

How it is built

One API for the web and the phone app, and a database that refuses to show one account's data to another, whatever the code above it gets wrong.

The database enforces tenancy

Every request runs as a role that row-level security always binds. A forgotten check returns nothing rather than someone else's data, and a read across accounts gets the same 404 as a record that does not exist.

One record per event

The proposal, any approval, registrations, attendance and the report all attach to the same row. Nothing is typed in twice.

Approvals are rows, not a service

Where a club works under an institution, its events go through a versioned state machine stored in Postgres. A running approval keeps the version it started on.

Adapters tell the truth

Email, calendar, files and billing each have a sandbox that records what it would have sent and says so. Nothing pretends to succeed.
