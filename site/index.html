The source is private. The public engineering notes explain the permissions, workflow and design decisions behind the product.

One durable event record

Draft, review, registration, attendance and close-out stay connected. Versioned workflows and concurrency checks protect decisions.

Tenant-bound access

NestJS and PostgreSQL enforce permissions and row-level security. The browser is never the authority for a club’s private data.

A shared visual language

React and Next.js use common design tokens, soft surfaces, consistent controls and motion that respects reduced-motion preferences.

A separate demo boundary

The static Firebase demo uses isolated sample data. It cannot create real accounts, send mail or modify a customer workspace.
